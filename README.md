# FinTrack — Personal Finance Dashboard

> A full-stack personal finance management system with JWT authentication, category-wise budget tracking, and a clean REST API — built with FastAPI and PostgreSQL.

🔗 **Live Demo:** [coming soon]  
📁 **GitHub:** [github.com/DevChinmaysamal17/FinTrack---Personal-Finance-Dashboard](https://github.com/DevChinmaysamal17/FinTrack---Personal-Finance-Dashboard)

---

## 🧩 What It Does

Most people lose track of where their money goes. FinTrack gives users a single dashboard to log income and expenses, set monthly budgets per category, and monitor financial health — all behind a secure authentication system.

---

## ✨ Features

### 🔐 Authentication & Security
- User Registration & Login
- JWT Token Authentication (OAuth2)
- Protected API routes
- Bcrypt password hashing

### 📊 Dashboard
- Financial overview with income vs expense summary
- User-specific data isolation
- Dynamic frontend rendering via Fetch API

### 💸 Transactions
- Add, view, update, delete transactions
- Income & expense categorization
- Filter by category and type

### 📁 Budget Management
- Create monthly budgets per category
- Real-time budget vs spending tracking
- Budget progress UI

### 🗂️ Categories System
- Create custom categories
- Income & expense category types
- Default categories auto-created on registration

## 🔌 API Reference

Interactive docs available at `/docs` after running the server (auto-generated by FastAPI).

### Authentication
| Method | Endpoint | Description |
|---|---|---|
| POST | `/login` | User login, returns JWT token |

### Users
| Method | Endpoint | Description |
|---|---|---|
| POST | `/users` | Register new user |
| GET | `/me` | Get current user profile |
| DELETE | `/users/{id}` | Delete user account |

### Categories
| Method | Endpoint | Description |
|---|---|---|
| POST | `/categories` | Create category |
| GET | `/categories` | List all categories |
| PUT | `/categories/{id}` | Update category |
| DELETE | `/categories/{id}` | Delete category |

### Transactions
| Method | Endpoint | Description |
|---|---|---|
| POST | `/transactions` | Add transaction |
| GET | `/transactions` | List all transactions |
| PUT | `/transactions/{id}` | Update transaction |
| DELETE | `/transactions/{id}` | Delete transaction |

### Budgets
| Method | Endpoint | Description |
|---|---|---|
| POST | `/budgets` | Create budget |
| GET | `/budgets` | List all budgets |
| PUT | `/budgets/{id}` | Update budget |
| DELETE | `/budgets/{id}` | Delete budget |

## ⚙️ Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/DevChinmaysamal17/FinTrack---Personal-Finance-Dashboard.git
cd FinTrack
```

### 2. Create and activate virtual environment
```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Mac/Linux
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Set up environment variables
```bash
cp .env.example .env
# Edit .env with your PostgreSQL credentials and secret key
```

### 5. Run the server
```bash
uvicorn Backend.main:app --reload
```

### 6. Open in browser
```
http://127.0.0.1:8000
```
